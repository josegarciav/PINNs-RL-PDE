# D01 / D02: optimizer baseline and the floor (in progress)

`run.py` runs Adam, L-BFGS and Adam→L-BFGS (switch ratios 0.3–0.9) at matched wall-clock time on heat, Burgers and Allen–Cahn, plus the heat-α floor cell of F01 with an L-BFGS finish. Full results pending; the floor part is in. **Finding so far:** on F01's cell (200 observations, noise 0.01) L-BFGS alone reaches an α error of 0.01 % and a field error of 0.14 %; plain Adam with the network's weight decay and gradient clipping off reaches 0.1 %. An ablation of the defaults (2 seeds, 5,000 Adam steps): defaults 2.6 / 1.6 % error of α; weight decay off 1.0 / 0.4 %; clipping off 1.8 / 0.3 %; both off 1.2 / 0.2 %, with the field error 2 % → 0.25 %. The 2 % "surrogate floor" of F01–F09 is largely the packaged regularization of the network; `experiments/F01_heat_alpha_recovery/run.py --clean` reruns F01 without it.
